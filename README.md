# A Nike Project – Power BI Dashboard

## 📊 Project Overview
This project is an interactive **Power BI dashboard** designed to analyze product sales with a strong focus on usability and clean visual design.

The dashboard enables intuitive, product-style exploration through image-based selection and clear KPI indicators.

---

## 🛠 Tools & Technologies
- Power BI  
- Power Query (Transform Data)  
- Data Modeling  
- Interactive Visuals (Cards & Image Slicers)

---

## 🔍 Key Features
- Image-based slicer for intuitive product selection  
- Multiple card visuals to highlight key performance metrics  
- Dynamic product information based on user selection  
- Clean, user-friendly dashboard layout  
- Data cleaned and structured using Power Query

---

## 📈 Key Metrics
- Total Sales  
- Average Rating  
- Number of Reviews
